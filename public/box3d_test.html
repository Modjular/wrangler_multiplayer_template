box3d-wasm determinism test

Runs a fixed physics scene for 600 steps (10 simulated seconds at a 1/60s fixed timestep, using world.step(1/60, 4) every call — not wall-clock time, so this is fair to compare across devices of very different speeds). Hashes the full body state once per simulated second. Run this on each device/browser you want to test, then compare the hash lists — they must match exactly, character for character, or the physics is not deterministic across that pair.
